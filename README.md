[Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232)
competition on [make.fun](https://make.fun).

## How it works

Running `main.py` (Python 3.13) writes exactly one line — the joke — to
`/output/entry.txt`. The output is deterministic: every run produces
byte-identical output, is UTF-8 text, a single line, and under 200 characters.

```sh
python3 main.py
```
